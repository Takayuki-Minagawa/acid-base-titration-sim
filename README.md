# 酸塩基滴定シミュレーター

酸塩基滴定と pH 変化をリアルタイムに観察できる Web 教材です。

## デモ

https://takayuki-minagawa.github.io/acid-base-titration-sim/

## 機能

- 強酸/弱酸 × 強塩基/弱塩基 の組み合わせによる滴定曲線
- ビュレット・ビーカーの Canvas アニメーション（液滴・波紋・スターラー・滴下直後の局所的な変色・指示薬の色変化、高 DPI 対応）
- 「1滴」ボタンで当量点付近を慎重に滴下、シークバーに当量点の目印
- pH スペクトルバーと pH メーター（現在の pH を色と位置で表示）
- 滴定曲線 SVG（pH に応じたグラデーション、当量点・半当量点マーカー、指示薬変色域の帯表示、ホバー／タッチで詳細）
- イオン濃度パネル（対数目盛、優勢なイオンの表示、緩衝領域ハイライト、Henderson–Hasselbalch 式表示）
- 学習パネル（滴定の進み具合ステッパー、状態連動の解説カード + クイズ 4 問と結果画面）
- 発見ノート（実験中に 9 つの「発見」を集める達成記録、ブラウザに保存）
- 初回ガイド（ヘッダーの「?」から再表示可能）
- 日本語／英語切替（i18n、選択を保存）
- ライト／ダークテーマ切替
- PC・タブレット・スマホ対応レスポンシブ UI（スマホでは下部に操作ドック）
- `prefers-reduced-motion` に対応（アニメーションを抑制）
- CSV エクスポート（現在までの滴定データ）

## 対応化学種

| 種別 | 化学種 | 備考 |
|------|--------|------|
| 酸（試料 or 滴下液） | HCl、H₂SO₄、CH₃COOH、H₃PO₄ | H₂SO₄ は 2 価として計算。H₃PO₄ は第 1 段のみ |
| 塩基（試料 or 滴下液） | NaOH、KOH、NH₃ | |
| 指示薬 | メチルオレンジ（3.1–4.4）、BTB（6.0–7.6）、フェノールフタレイン（8.3–10.0） | |

## 技術スタック

- React 19 + TypeScript + Vite
- Tailwind CSS v4
- i18next / react-i18next
- Canvas 2D（実験アニメーション）
- SVG（滴定曲線）

## ローカル実行

```bash
npm install
npm run dev
```

## デプロイ

`main` ブランチへ push すると GitHub Actions が自動的に GitHub Pages へデプロイします。
